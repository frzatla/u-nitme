# U-NIT ME

An AI-powered course planning web app for Monash University students. Enter your degree details and get a personalized, semester-by-semester course roadmap — instantly.

Built for the **UniHack** hackathon.

---

## Features

- **Personalized course plans** — generated by a Python scheduling algorithm using DAG critical-path analysis
- **Prerequisite-aware scheduling** — units are sequenced correctly based on prerequisite chains
- **Unit difficulty ratings** — every unit gets a difficulty score (Low / Moderate / Hard / Very Hard) computed from mock student GPA and grade data, propagated through the prerequisite graph
- **Interactive plan editor** — drag and drop units between semesters; rename plans inline
- **Unit details** — view offerings, assessments, and requisites pulled from the Monash Handbook
- **Student reviews** — see real r/Monash Reddit discussions for any unit
- **Save & manage plans** — authenticated dashboard to store and revisit plans
- **PDF export** — download your course plan as a formatted PDF
- **Elective search** — search Monash units by keyword, code, or level to fill free elective slots (powered by Typesense)
- **AI course advisor** — floating "ChatJKW" chatbot (Google Gemini + Typesense RAG) for degree planning advice
- **AI elective recommender** — purpose-built AI tab inside the elective search for unit-by-unit suggestions
- **Admin panel** — role-gated dashboard to add units to the dataset and view scheduling analytics

## How It Works

1. Sign in via Clerk — admins are redirected to `/admin`, everyone else to `/dashboard`
2. Choose your **course**, **area of study**, and optional **major/minor**
3. The server runs `algo1.py` — a Python scheduler that maps out your full degree using DAG critical-path analysis
4. Every unit on the plan gets a **difficulty score** computed from mock student enrolment data and propagated through the prerequisite graph
5. Your plan is saved to Supabase and displayed as an interactive semester grid
6. Click any **Free Elective** slot to search units or ask the AI chatbot for suggestions
7. Click any unit to view handbook details, difficulty breakdown, and Reddit reviews
8. Use the floating **ChatJKW** chatbot for broad degree-planning advice at any time
9. Drag and drop to reorder, rename the plan inline, export to PDF, then save

## Getting Started

### Prerequisites

- Node.js 18+
- Python 3 (for the scheduling algorithm)
- A [Clerk](https://clerk.com) account
- A [Supabase](https://supabase.com) project
- An [Elastic Cloud](https://cloud.elastic.co) deployment
- A [Typesense Cloud](https://cloud.typesense.org) cluster (or self-hosted)
- An [Upstash Redis](https://upstash.com) database
- A [Google AI Studio](https://aistudio.google.com) API key (Gemini)

### Installation

```bash
git clone https://github.com/frzatla/u-nitme
cd u-nitme/my-app
npm install
```

### Environment Variables

Create `my-app/.env.local`:

```
# Clerk
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=

# Supabase
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_DEFAULT_KEY=

# Elasticsearch (Elastic Cloud)
ELASTICSEARCH_CLOUD_ID=
ELASTICSEARCH_API_KEY=

# Typesense
TYPESENSE_HOST=
TYPESENSE_SEARCH_KEY=

# Upstash Redis (chat session persistence)
UPSTASH_REDIS_REST_URL=
UPSTASH_REDIS_REST_TOKEN=

# Google Gemini (AI chatbot)
GOOGLE_AI_API_KEY=

# Admin access (comma-separated emails, or set role=admin in Clerk publicMetadata)
ADMIN_EMAILS=
```

### Index Search Data (one-time setup)

After setting your env vars, index the unit database:

```bash
cd my-app

# Typesense (unit search + AI chatbot RAG — units, AOS, courses)
node scripts/index-typesense.js

# Elasticsearch (optional — offline analytics/indexing only)
node scripts/index-units.js
```

### Run

```bash
cd my-app
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Difficulty Scoring

Each unit on a generated plan gets a difficulty score (0–100) computed at request time from mock student data stored in `algo/src/data/`:

- **Direct score** — derived from cohort GPA, grade points, GPA drop, fail rate, and unit level
- **Prerequisite propagation** — scores are propagated 8 passes through the prerequisite DAG; a unit inherits difficulty from its hardest prerequisite chain
- **Levels**: Low (< 42) · Moderate (42–59) · Hard (60–74) · Very Hard (75+)
- Units with no student data receive a **synthetic score** based on level and prerequisite depth so the UI never shows "Not calculated"
